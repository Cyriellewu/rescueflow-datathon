Hard limit 3:00. Target 2:50. Every number on screen must come from `docs/evaluation.md`,
`docs/METHODS.md` or the dashboard itself (regenerated on real data). Every lab number is a
simulation and is badged as one on screen. Rubric line in brackets.

## Recording checklist

- [ ] Dashboard served from the VM (public IP or SSH tunnel), not a laptop
- [ ] Demo hour: 2026-07-04 23:00 Brooklyn (caught an hour early; next-hour median low-acuity dispatch wait 47 min vs 26-min norm). Read the risk figure off the tile at recording time; do not quote one from memory. Alternates in `artifacts/demo_moments.json`
- [ ] Parallel Worlds: default pair (no reserves vs AI-timed), press "Jump to the biggest gap", keep the SIMULATION badges in frame
- [ ] Never say "live 911", "saves lives" or a number of minutes saved in real life; every lab number is "in the simulation"
- [ ] Say "replayed" or "backtest", not "live"; the sidebar's "Not a live feed" line stays visible
- [ ] Voice-over is about 540 words, a brisk read (roughly 190 words a minute to land at 2:50). Timer check after the first take; cut the 2:05–2:25 hospital scene first if long, then the 0:15–0:30 chart
